# AI × Web3 School Cohort 0 Learning Repo

Personal learning repository for AI × Web3 School.

## Learner Profile

- AI: 有基础
- Web3: 新手
- Programming: 无代码
- Goal: Hackathon
- Daily time budget: 1 小时

## Learning System

- `learning-plan.md`: personal learning plan and weekly milestones
- `daily/`: daily check-in drafts and logs
- `tasks/`: task breakdowns and submission notes
- `handbook-feedback/`: feedback issues for the Handbook
- `notes/`: concept notes and summaries
- `experiments/`: no-code or AI-assisted experiments
- `hackathon/`: hackathon idea, validation, pitch, and prototype notes
- `submissions/`: final task and project submission materials
- `templates/`: reusable daily and feedback templates
