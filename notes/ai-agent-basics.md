# AI Agent Basics

## One-Sentence Definition

An AI Agent is a goal-oriented AI system that can understand user intent, plan steps, use tools, keep context, and produce concrete results.

## Agent vs Chatbot

| Topic | Chatbot | AI Agent |
| --- | --- | --- |
| Goal | Answers the current question. | Works toward a user goal or task outcome. |
| Planning | Usually responds turn by turn. | Can break a goal into steps and track progress. |
| Tool use | May not use external tools. | Can use tools such as files, GitHub, browser, terminal, or reminders. |
| Memory/context | Mainly depends on current conversation context. | Maintains task context, user preferences, repo state, and next actions. |
| Output | Gives an answer, explanation, or suggestion. | Produces proof-of-work such as files, commits, notes, checklists, or submitted tasks. |

## My Understanding

我理解，Agent 可以快速理解 user 的目的和实现方向，拆解步骤，并一步步自动化执行。

Chatbot 更像是一种“十万个为什么”式的对话工具，主要负责回答问题、解释概念或给建议，但通常不会持续追踪目标、调用工具并完成具体交付。

更准确地说：Chatbot 不一定完全“只回答不执行”，因为有些 Chatbot 也能调用工具；但 Agent 的重点是围绕目标持续推进，把“理解 → 计划 → 执行 → 检查 → 产出”串成一个工作流。

## Hermes Agent

Hermes can help me with:

- Learning plan: turn my AI × Web3 goal into weekly and daily tasks.
- GitHub repo: organize learning notes, tasks, demos, prompts, and logs.
- Daily records: remind me to check in and write daily proof-of-work.
- Task submission: prepare links, screenshots, and summaries for course tasks.
- Handbook feedback: record confusing points and turn them into structured feedback.
- Proof-of-work: produce visible artifacts instead of only saying “I studied today.”

## My Learning Workflow With Hermes

1. Tell Hermes my learning goal and current context.
2. Ask Hermes to break the goal into daily tasks.
3. Study or experiment for one focused session.
4. Let Hermes help organize notes, feedback, and proof-of-work.
5. Commit the output to GitHub and use it for course submission.
