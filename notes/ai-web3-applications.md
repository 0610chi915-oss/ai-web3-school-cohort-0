# AI × Web3 Applications

## My Current Understanding

AI × Web3 is valuable when the same product needs both intelligence and a trust layer.

今天课程里的一个核心观点是：AI × Web3 的核心不是发币，而是经济基础设施。当 AI Agent 从“回答问题”走向“执行任务”时，它需要的不只是模型能力，还需要算力、存储、数据、钱包账户、支付能力、链上记录、交易授权、风控和可验证的执行环境。

## Application Map

| Application | User | Pain Point | AI Capability | Web3 Capability | Hackathon Potential |
| --- | --- | --- | --- | --- | --- |
| Decentralized AI infrastructure | AI builders / agent developers | AI needs compute, storage, data, and model services. | Model inference, task automation, data processing. | Decentralized compute, storage, data networks, and resource markets. | Medium: good for research, but hard for no-code prototype. |
| AI Agent + wallet | Agent users / crypto users | Agents need identity, accounts, payment, and asset execution. | Understand user goals and automate actions. | Wallet identity, payment, transfer, authorization, and execution. | High: can prototype an agent wallet flow. |

| Exchange / DeFi risk control | Traders / platforms | Fraud, phishing, abnormal transactions, and market risk are hard to monitor. | Risk detection, anomaly analysis, and alerting. | Transaction records, KYC-related flows, DeFi parameters, and smart contract activity. | Medium: useful but may need data access. |

## Five Directions From Class

1. 去中心化 AI 基础设施：算力、存储、数据、模型服务。
2. AI Agent + 钱包：身份、资产账户、支付能力、执行权限。
3. AI 链上分析工具：把复杂链上数据翻译成人能理解的判断。
4. 智能钱包和安全助手：解释签名、授权、转账和风险。
5. 交易所和 DeFi 风控：识别欺诈、异常交易、攻击预警。

## AI × Web3 Project Matrix

### 基础设施

- Examples: Bittensor、Render、Akash、Filecoin / Arweave
- Key idea: AI 需要算力、存储、数据；Web3 提供去中心化资源网络。

### Agent 钱包

- Examples: Coinbase AgentKit、MoonPay Agents、Virtuals、elizaOS
- Key idea: AI Agent 需要执行支付、交易、资产操作；Web3 钱包提供身份和资产入口。

### 链上分析

- Examples: Arkham、Nansen、Dune、Bubblemaps
- Key idea: AI 帮助理解复杂链上数据；Web3 提供透明但难读的公开数据。

### 钱包安全

- Examples: Safe、Rabby、Blockaid
- Key idea: AI 解释交易和识别风险；Web3 提供真实资产和权限管理场景。

### 风控

- Key idea: 风控是围绕交易、合约、身份或市场风险，识别欺诈、异常交易和潜在攻击。

## Case Study: 智能钱包和安全助手

- 场景：普通用户使用 Web3 钱包时，不理解签名、授权、交易风险。
- AI 作用：理解交易内容，解释签名含义，识别钓鱼、恶意授权、异常交易。
- Web3 作用：钱包身份、链上交易、智能合约调用、资产授权和权限管理。
- 组合价值：AI 让 Web3 钱包更好懂、更安全；Web3 提供真实交易和资产场景。
- Hackathon 潜力：很高，尤其适合做一个“交易前 AI 风险解释器”或“钱包安全 Copilot”。

## Good AI × Web3 Project Checklist

- [ ] The problem needs AI, not just a normal form or dashboard.
- [ ] The problem needs Web3, not just a normal database.
- [ ] There is a clear target user.
- [ ] The demo can show a simple user journey.
- [ ] The Web3 part can be explained without deep technical jargon.
- [ ] The AI part creates visible user value.
