# Handbook Feedback Workflow

Use this folder to turn every confusion, broken link, unclear task, or improvement idea into structured feedback.

## When to Create Feedback

- A Handbook instruction is unclear.
- A task lacks expected output or submission format.
- A page has a broken link or outdated information.
- A beginner Web3 concept needs more explanation.
- A no-code learner may get blocked.

## Feedback Process

1. Create a new file: `handbook-feedback/YYYY-MM-DD-short-topic.md`.
2. Fill in the template from `templates/handbook-feedback.md`.
3. If useful, include page URL, screenshot path, and suggested wording.
4. Review feedback weekly and submit through the official feedback channel if available.

## Feedback Principles

- Be specific: quote the confusing section briefly or summarize it.
- Explain learner impact: why a beginner may get blocked.
- Suggest a fix: add example, clarify output, add prerequisite, or update link.
- Keep each file focused on one issue.
